# Carlos Desktop

Installateurs officiels de **Carlos Desktop** pour macOS et Windows.

Carlos connecte ton ordinateur au dashboard Carlos sans Terminal, npm ni configuration développeur.

## Installation

- **macOS** : télécharge Carlos-Mac-universal.dmg, ouvre le DMG, puis lance Carlos.
- **Windows** : télécharge Carlos-Windows-Setup.exe et suis l'installation.

Ensuite, dans le dashboard Carlos : **Ordinateurs → Associer un ordinateur → Ouvrir Carlos et associer**.

> Le code source principal de Carlos reste privé. Ce dépôt sert uniquement à distribuer les installateurs.
